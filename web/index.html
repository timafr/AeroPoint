⚡ Вариант 1 (Рекомендуется): Запуск БЕЗ установки и без .IPA

Вам не нужно компилировать .ipa или мучиться с сертификатами Apple! В приложении уже встроен веб-контроллер для Safari:

  1. Убедитесь, что iPhone и ПК в одной сети Wi-Fi.
  2. Откройте Safari на iPhone и перейдите по адресу: http://<IP_КОМПЬЮТЕРА>:5000/mobile (или отсканируйте QR-код на панели).
  3. Нажмите «Разрешить камеру» — отслеживание кисти и управление курсором ПК заработает моментально!

☁️ Вариант 2: Бесплатная авто-сборка .IPA в облаке (GitHub Actions)

Так как Windows не содержит компилятор Apple Clang и iOS SDK, мы добавили готовый файл автоматической сборки .github/workflows/build_ios.yml, который собирает настоящий .IPA на бесплатном сервере Mac в облаке GitHub:

  1. Загрузите ваш проект в репозиторий GitHub.
  2. Перейдите во вкладку Actions → выберите Build AeroPoint Spatial iOS IPA.
  3. Нажмите Run workflow — через 2 минуты сборка завершится.
  4. В блоке Artifacts скачайте готовый архив AeroPointSpatial.ipa!

📲 Как установить скачанный .IPA на iPhone с Windows (Sideloadly):

  1. Скачайте бесплатную утилиту Sideloadly для Windows (sideloadly.io).
  2. Подключите iPhone кабелем Lightning/Type-C к компьютеру.
  3. Перетащите файл AeroPointSpatial.ipa в окно Sideloadly.
  4. Введите ваш Apple ID (для бесплатной цифровой подписи) и нажмите Start.
  5. Через 30 секунд приложение появится на экране вашего iPhone!
💡 Если у вас или друга есть Mac: просто откройте папку ios/AeroPointSpatial в Xcode и нажмите кнопку Run ▶.

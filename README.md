# ✋ AeroPoint Quantum 3.0 | Neural Spatial HCI & iPhone LiDAR Controller

> **Проект человеко-машинного пространственного интерфейса (Spatial HCI) реального времени на основе компьютерного зрения, нейросетевого трекинга рук, аппаратных сенсоров Apple LiDAR / TrueDepth и Motion Design.**

## 🌟 Революционные возможности версии 3.0

### 1. 📱 iPhone Spatial Sensor (LiDAR & TrueDepth Face ID)
- **Прямая аппаратная трансляция метрической 3D-глубины ($Z$ в миллиметрах)** с частотой 60 FPS по локальной сети Wi-Fi или USB.
- **Инверсионно-устойчивый задний LiDAR (Inversion-Proof Rear LiDAR)**:
  - Автоматическая и ручная коррекция горизонтальной инверсии ($nx' = 1.0 - nx$) и смена хиральности (`Left` ⇄ `Right`), когда iPhone стоит спиной к пользователю.
  - Движение руки вправо на заднем лидаре перемещает курсор строго вправо!
- **Динамическая ориентация**: полная поддержка как вертикального (Portrait), так и горизонтального широкоформатного (Landscape) режима смартфона.
- **Screen Wake Lock & Фоновый режим**: экран iPhone не тускнеет и не гаснет во время активной сессии управления.
- **Автономный установочный IPA**: готовый скомпилированный файл лежит прямо в репозитории: `AeroPointSpatial.ipa` (также доступен по прямой ссылке `/download/ipa` в веб-интерфейсе).

### 2. 🖐️ Система «5 Основных Жестов» (The Essential 5)
Устранена путаница десятка сложных поз. Оставлены только 5 железобетонных, естественных и эргономичных движений:
1. **Hover (Наведение)**: Указательный палец поднят — плавное, сверхточное перемещение курсора без дрожания.
2. **Pinch / Tap (Клик ЛКМ)**: Касание подушечками большого и указательного пальцев ($d_{\text{norm}} < 0.28$) со строгим контролем глубины 3D ($\Delta Z < 35\text{ мм}$). Ложные нажатия полностью устранены!
3. **Pinch-and-Hold / Fist (Перетаскивание Drag & Drop)**:
   - Удержание щипка дольше 0.22 сек (или сжатие в кулак) плавно захватывает и удерживает левую кнопку мыши.
   - Разжатие пальцев отпускает объект. Никаких случайных сбросов!
4. **Right Click (Контекстное меню ПКМ)**: Касание кончиком среднего и большого пальцев. Мгновенный вызов контекстного меню.
5. **Smooth Scroll (Инерционная прокрутка)**: Указательный и средний пальцы подняты вместе (V-знак).
   - Интегрирован физический движок **кинетического затухания моментума** (Kinetic Inertial Momentum Scroll, как на трекпадах Apple).
6. **Safety Pause (Защитный нейтраль)**: Раскрытая ладонь (5 пальцев) замораживает курсор, позволяя безопасно размять руку.

### 3. ⭕ Голографический Quick-Dial (Радиальное Меню)
Инновационная круговая панель быстрого доступа на 8 секторов:
- **🪟 Обзор окон** (`Win + Tab`)
- **✂️ Ножницы** (Снимок экрана `Win + Shift + S`)
- **🔊 / 🔉 Громкость** (+/-)
- **▶️⏸️ Медиа** (Play / Pause)
- **💻 Рабочий стол** (`Win + D`)
- **🔍 Лупа / Масштаб** (`Win + Plus`)
- **🔒 Блокировка ПК** (`Win + L`)

### 4. 🎵 Web Audio Пространственный Синтезатор
Полностью синтетический, реактивный звуковой движок без внешних аудиофайлов:
- Оптические щелчки (High-pass Click 2.4 kHz) при наведении и нажатиях.
- Стеклянные колокольчики (Crystal Chime 1.2 kHz) для правого клика.
- Низкочастотный кинетический гул (Deep Sub Bass 65 Hz) в режиме Drag & Drop.
- Механическая трещотка (Ratchet Tick) при инерционной прокрутке.
- 3 звуковых темы: *Quantum Neon*, *visionOS Glass*, *Cyber Bionic*.

### 5. 🖥️ Мультимониторный режим и Windows Aero Snap
- Поддержка многомониторных конфигураций с отрицательными экранными координатами Windows (`SM_XVIRTUALSCREEN`, `SM_YVIRTUALSCREEN`).
- Курсор свободно перемещается между мониторами, расположенными слева или сверху от основного экрана.
- Полноценная поддержка Per-Monitor High-DPI масштабирования.
- **Aero Snap для окон**: быстрое прикрепление активных окон к левой/правой половине экрана (`Win+Left`, `Win+Right`), разворачивание (`Win+Up`) и сворачивание (`Win+Down`).

### 6. 🎡 Голографический 3D виртуальный скролл-барабан (Virtual Scroll Cylinder HUD)
- При прокрутке двумя пальцами (жест Scroll) в воздухе рядом с рукой проецируется парящая 3D-капсула виртуального ролика мыши.
- Синусоидальная оптическая проекция меток ($y_i = cy + R \cdot \sin(\theta_i + \text{phase})$) имитирует физическое вращение цилиндра.
- Динамические направляющие шевроны (`▲` вверх, `▼` вниз) и кинетическое затухание скорости (`InertialScrollEngine`).

### 7. 🎯 Профили кинетики и адаптивное энергосбережение
- **3 профиля сглаживания 1-Euro**:
  - `Дизайн & CAD`: усиленная фильтрация (`min_cutoff=0.45`, `deadzone=4.2px`) для Figma, Blender, CAD.
  - `Базовый десктоп`: сбалансированный режим для повседневной работы (`min_cutoff=0.85`, `deadzone=3.5px`).
  - `Экшен & Презентации`: минимальная задержка (`min_cutoff=1.65`, `deadzone=1.8px`).
- **🌱 Адаптивный режим ожидания (Dynamic ECO)**: при отсутствии руки в кадре конвейер снижает частоту до 15 FPS (экономия 75% CPU), мгновенно просыпаясь до 60 FPS Turbo за 1 кадр при появлении руки.

### 8. 🧭 3D-ориентация ладони (Roll/Pitch) и авиагоризонт
- Тригонометрический расчет угла наклона плоскости костяшек пальцев (`roll_deg` от `INDEX_MCP` к `PINKY_MCP`) и угла подъема кисти (`pitch_deg`).
- Отрисовка динамической планки авиагоризонта (Artificial Horizon Leveler), вращающейся синхронно с наклоном ладони пользователя.

### 9. 🩺 Глубокая системная диагностика (`/api/diagnostics`)
- Интерактивная панель мониторинга здоровья подсистем прямо в веб-интерфейсе:
  - Живое потребление оперативной памяти процесса (RSS в MB).
  - Нагрузка на центральный процессор (CPU %).
  - FPS и задержка конвейера в миллисекундах.
  - Сетевые счетчики сокета iPhone TrueDepth / LiDAR (порт UDP 8765).
  - Экспресс-тест подсистем с проверкой RTT отклика API.

### 10. 💎 AeroPoint Quantum 3.0 — visionOS Glassmorphic Interface
- Вертикальный док навигации в стиле Apple Vision Pro: *Студия*, *5 Жестов*, *Quick-Dial*, *Точность*, *iPhone LiDAR*, *Air-Keys*, *Звуки FX*, *Диагностика*.
- Кибернетический прицел HUD со световым плазменным шлейфом (Plasma Ribbon Trail), 3D-датчиком глубины Z и калипером дистанции в сантиметрах.
- Фоновая интерактивная звездная туманность (Ambient Starfield Canvas).

## 🛠️ Установка и запуск

### 1. Требования к окружению
- **ПК**: Windows 10 / 11 (или Linux / macOS с базовой эмуляцией)
- **Python**: 3.10 – 3.13
- **Камера**: Веб-камера ноутбука/USB или iPhone (iOS 15.0+ с Face ID или LiDAR)

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск AeroPoint Studio
```bash
python app.py
```
*Запустит приложение с нативным окном в стиле visionOS и локальным веб-сервером на порту 5055.*

Для запуска только в браузере:
```bash
python app.py --browser
```

### 4. Подключение iPhone:
1. **Вариант А (Через Safari без установки приложений)**:
   - Откройте Safari на телефоне и перейдите по адресу: `http://<IP-вашего-ПК>:5055/mobile` (или отсканируйте QR-код во вкладке *iPhone LiDAR*).
   - Нажмите «Разрешить камеру» — готово!
2. **Вариант Б (Нативное приложение iOS с ультранизкой задержкой)**:
   - Скачайте готовый `AeroPointSpatial.ipa` прямо из интерфейса или папки проекта.
   - Установите на iPhone через AltStore / Sideloadly / TrollStore.
   - В приложении введите IP вашего ПК и управляйте компьютером на частоте 60 FPS!

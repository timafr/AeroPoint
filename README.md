# ✋ AeroPoint Studio | Neural Kinetic Gesture Interface

> **Проект человеко-машинного интерфейса (HCI) реального времени на основе компьютерного зрения, нейросетевого трекинга рук и Motion Design.**
> Полная реализация программно-аппаратного комплекса по спецификации индивидуального исследовательско-инженерного проекта.

---

## 🚀 Ключевые возможности

- **AeroPoint Motion Design Интерфейс**: Пространственный кибернетический интерфейс с живой динамической аурой, 3D-параллаксом карточек наведение курсора, кинетическими прицельными скобами видоискателя и нейро-эквалайзером.
- **Точное определение камер DirectShow**: Автоопределение реальных названий физических и виртуальных камер Windows через COM DirectShow без рассинхронизации индексов.
- **Два режима клика ЛКМ**:
  - **Сгиб большого пальца (Thumb Bend)**: Клик по сгибу межфалангового сустава ($< 132^\circ$) — указательный палец и курсор остаются неподвижными!
  - **Щипок (Pinch)**: Классический кинематический щипок большим и указательным пальцами.
- **Тихий клик**: Полное отсутствие системных звуков Windows при нажатиях мыши (звук ошибки Windows полностью устранен). Опциональный синтез тихого клика через Web Audio API.
- **Zero-Cost Hardware Pipeline**: Работает с любой стандартной 2D веб-камерой (720p / 1080p) ноутбука или USB.
- **Нейросетевой трекинг**: Модель **MediaPipe Hand Landmarker** в реальном времени локализует 21 трехмерную ключевую точку скелета кисти (x, y, z).
- **Математический аппарат**:
  - Нормализация масштаба ладони (расстояния инвариантны к удалению руки от камеры).
  - Расчет углов сгиба фаланг по **теореме косинусов**: $\cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\| \|\mathbf{v}\|}$.
  - Евклидово расстояние между управляющими фалангами: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$.
- **Борьба с тремором и дрожанием (Anti-Jitter)**:
  - **Адаптивный фильтр EMA**: Динамический коэффициент $\alpha \in [0.20, 0.85]$ в зависимости от скорости руки (полное подавление шума в покое и мгновенная реакция при взмахе).
  - **Мертвая зона (Deadzone)**: Блокировка микроколебаний ($\Delta r < 4\text{px}$) для надежного клика по мелким элементам и кнопкам ОС.
  - **Debounce & Hysteresis**: Порог сжатия щипка (0.28) разделен с порогом отпускания (0.40), кулдаун 250 мс исключает ложные двойные клики.
- **Сверхбыстрый ввод Windows**: Прямой низкоуровневый вызов `User32.dll` (`SetCursorPos`, `mouse_event`) с задержкой диспетчеризации **0.004 мс** (в 100 раз быстрее стандартного PyAutoGUI).
- **Киберпанк HUD-интерфейс**: Живая телеметрия (FPS, Latency, CPU Load, Active Gesture, 21 Joints), неоновый скелет руки, зона контроля и график подавления тремора.
- **CLAHE Режим**: Адаптивное выравнивание гистограммы в пространстве LAB для устойчивой работы при слабом освещении комнаты.

## ✌️ Словарь жестов (Gesture Cheatsheet)

| Жест | Иконка | Поза руки | Действие в ОС | Описание |
| :--- | :---: | :--- | :--- | :--- |
| **Hover** | ☝️ | Указательный поднят, остальные сомкнуты | Перемещение курсора | Плавная трансляция координат кончика указательного пальца на экран |
| **Pinch Click** | 🤏 | Смыкание большого и указательного пальцев | Левый клик (ЛКМ) | Срабатывает при $d_{\text{norm}} < 0.28$, отпускается при $> 0.40$ (с эффектом shockwave) |
| **Right Click** | 👌 | Смыкание большого и среднего пальцев | Правый клик (ПКМ) | Вызов контекстного меню в точке курсора |
| **Scrolling** | ✌️ | Указательный и средний подняты (V-знак) | Колесико мыши (Scroll) | Движение кисти вверх прокручивает страницу вверх, вниз — вниз |
| **Drag & Drop**| ✊ | Сжатие ладони в кулак | Зажатие ЛКМ (Mouse Down) | Удерживает ЛКМ для перетаскивания файлов и окон; разжатие кулака отпускает кнопку |
| **Pause** | 🖐️ | Полностью раскрытая ладонь (5 пальцев) | Блокировка управления | Защитный режим: безопасное перемещение руки без движения курсора |

## 📂 Структура проекта

```
c:\hands\
├── hand_landmarker.task   # Обученная нейросетевая модель MediaPipe (Tasks API)
├── config.py              # Конфигурация порогов, сглаживания, камеры и палитры HUD
├── filters.py             # Фильтры EMA, Adaptive EMA, 1-Euro Filter и Deadzone
├── hand_tracker.py        # Захват кадров, CLAHE, вычисление FPS и 21 точки суставов
├── gestures.py            # Математика углов, расстояний и конечный автомат жестов
├── mouse_controller.py    # Сверхбыстрая эмуляция мыши через Windows User32 C API
├── hud.py                 # Отрисовка Cyberpunk HUD, скелета, графика шума и рипплов
├── main.py                # Главный модуль запуска с оконным интерфейсом и горячими клавишами
├── benchmark.py           # Автоматический стресс-тест скорости, фильтров и нагрузки ЦП
├── requirements.txt       # Зависимости Python
└── README.md              # Документация проекта
```

## 🛠️ Установка и запуск

### 1. Требования к окружению
- **ОС**: Windows 10 / 11 (или Linux / macOS с PyAutoGUI)
- **Python**: 3.10 – 3.13
- **Оборудование**: Встроенная или внешняя веб-камера

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск приложения

#### Вариант А: Современный Apple GUI (Рекомендуется)
```bash
python app.py
```
*Запустит приложение с нативным окном в стиле macOS Sequoia / visionOS: выбор камеры из выпадающего списка, ползунки фильтрации, переключатели и живой видоискатель.*

Если хотите открыть интерфейс в браузере:
```bash
python app.py --browser
```

#### Вариант Б: Легковесный HUD-режим (OpenCV)
```bash
python main.py
```

### Дополнительные параметры командной строки:
```bash
# Выбор другой камеры (например, внешней USB-камеры #1)
python main.py --camera 1

# Запуск с включенным режимом ночной съемки CLAHE
python main.py --clahe

# Отключение звукового щелчка при клике
python main.py --no-sound

# Настройка разрешения захвата
python main.py --width 640 --height 480
```

## ⌨️ Горячие клавиши во время работы

| Клавиша | Функция |
| :---: | :--- |
| **Q** / **ESC** | Завершить работу программы и освободить камеру |
| **C** | Включить / выключить адаптивное освещение **CLAHE** (для полумрака) |
| **H** | Показать / скрыть панель телеметрии **HUD** |
| **S** | Включить / выключить визуализацию скелета кисти |
| **P** | Ручная блокировка / разблокировка управления (**Safety Pause**) |
| **R** | Сбросить историю сглаживающих фильтров |
